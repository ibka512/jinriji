# v1.0 · 发布候选版

用户已批准开始开发。承接未提交的 v0.10，不重置已有工作；不自动提交、推送或部署。本轮版本标为 `1.0.0-rc.1`，完成本地验收后仍需真实设备放行，不能把候选版表述为已正式发布。

## 设计约束

Redesign · Preserve：日常写作、整理和学习工具。近距离手机与桌面阅读，安静的和纸温度；单行工具配合渐进显示，不增加装饰性文案。

- 五项校准：视觉变化 3、动效 3、信息密度 6、资产依赖 2、品牌保真 9。保留朱红软件图标、本地 Noto Serif SC、苔庭等四主题、纯文字侧栏、胶囊与圆形新建。
- 继续用现有 `--ink` / `--ink-soft` / `--paper-solid` / `--control-bg` / `--focus-ring`，不新增色相。间距以 4/8px 为基准，控件 14px 圆角、纸面 22px、导航胶囊、图标按钮圆形；阴影继续使用现有主题变量。
- 输入、撤销、键盘操作即时；指针状态 140ms，菜单 180ms 淡入淡出，短表单 240ms，导航沿用 UI-001。只动画 transform/opacity 与必要的状态颜色，不动画全文/列表高度。
- 保留原生 details/dialog 语义；不支持新 CSS 的引擎自然降级为即时开关。焦点、操作结果和数据提交不依赖动画结束。
- 保护：路由、记录 ID、数据库 v3、备份 v6、旧格式读取、草稿和历史；不新增生产依赖。最高风险为动效结束与存储/导航竞态，用隔离回归验证。
