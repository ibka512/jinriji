# 今日记

今日记是一款融合便签、待办、日程与课程表的响应式个人生活工具。视觉上结合液态玻璃操作层、莫奈式动态配色和现代和风氛围。

## v0.7 · 长期使用效率

- 侧栏移除「今」字印章，保留纯文字品牌，调整宽度、间距、对齐和底部状态；窄侧栏保留可读品牌。
- 侧栏与手机 Tab Bar 共用两态图标：未选中为线框、选中为带镂空细节的实心图形，继续提供 aria-current 与文字名称。
- 记录支持置顶、标签、按标签筛选和仅看置顶；搜索也可匹配标签。每条最多 12 个标签，每个最多 20 字。
- 记录页的“整理”支持当前结果全选、批量置顶／取消置顶、添加标签、完成待办及移至最近删除。删除需确认，发生版本冲突则整批回滚；切换筛选或页面会清空选择。
- 待办可按原计划每天／每周／每月重复，完成后生成一个下一次，逾期时跳过遗漏日期。月末在短月收拢，但保留原日号，之后恢复；不预先堆积未来任务。
- 快捷操作：`N` 按当前页面新建、`/` 搜索、`Alt + 1–4` 切换页面、`?` 查看帮助；保留 `⌘ / Ctrl + K` 快速记录和 `⌘ / Ctrl + Enter` 保存。输入文字时不触发单键操作。
- 离线时显示简短提示，设置区区分离线页面是否就绪；开发预览不缓存页面。网络提示不代表云同步，也不用于禁用编辑。
- 完整备份升级为 v4，包含置顶、标签、重复规则及下一次关联，继续读取 v1/v2/v3。无新增依赖、不升级数据库、不批量改写旧记录。

首次使用：记录卡右上角可置顶；编辑器“标签”可分类；记录页“整理”可批量操作。编辑待办时设置日期并选择“重复”，关闭重复请编辑尚未完成的下一次待办。

重复规则保留设置时的时区。撤销完成会同时撤销未编辑的自动生成项；如果下一次已经编辑、删除或完成，会拒绝撤销，保护后续内容。导入恢复会递增版本，因此不会把恢复后的下一次视作“未编辑”。完成历史仍可查看下一次；删除过去的一次不会删除下一次。

网络提示参考 [MDN navigator.onLine](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/onLine) 的限制，只提供提示；离线页面就绪依据 [Service Worker 控制状态](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/controller)，不保证未缓存字体可用。数据仍应定期导出。

## v0.6 · 课程与学习安排

- 学期：设置第一周周一、1–60 周及当前学期；按学期切换查看，保留历史课程
- 排课：每门课程可设置多个时段，支持每周／单双周、起止周、上课时间和地点
- 单次调整：点击具体课次调课或停课，可恢复原安排，不修改其他课次
- 课程表：手机按日阅读，宽屏按时间轴查看一周；重叠课程并排，时间范围随本周课程收拢
- 课程关联记录：从课程详情记笔记，也可在记录编辑器关联便签／待办／日程；删除课程不删除笔记
- 计划分段切换采用 [UI-001 · Segmented Switch](https://github.com/ibka512/ibka-ui-designs/tree/main/components/segmented-switch)：等宽胶囊、一个共享滑块、按压反馈和颜色过渡；适配深色、键盘与减少动态
- 新完整备份格式 v3 包含学期、排课规则与单次调整；仍可导入 v1/v2，并支持全表事务回退
- 沿用数据库版本与已有表，无新增生产依赖，不自动转换旧单次课程

使用顺序：计划 → 课程表 → 新建学期 → 添加课程 → 打开课程详情 → 添加时段。之后点击课程表中的具体课次进行调整。

学期时区固定为创建时的设备时区；跨时区查看时，课程表按学期当地时间显示，首页及本周安排按设备时间显示。单双周以学期第一周为准。当前不提供跨夜课、跨学期调课、教务导入、系统提醒或云同步。

## v0.5 · 日常可用

- 首页、日期、待办数量、本周安排和明日预览接入真实数据；固定示例不再混入用户视图
- 便签与事项的详情、编辑、类型转换；标题选填，保留原文换行，搜索标题和正文
- 待办按逾期、今天、以后、未设日期分组；已完成折叠，勾选后跨页面保持一致
- 自建课程可修改名称和首次时间、删除、恢复；首次安排可显示在本周日程中
- 按记录独立暂存编辑草稿；刷新、关闭或浏览器返回后可继续；编辑冲突可另存为新记录
- 最近删除、导入预览、记录级校验与原子恢复点；导入失败不改变原数据
- 手机全屏编辑与键盘可视区域适配；宽屏列表／详情并排；返回保留搜索、筛选与列表位置
- 安全更新按钮明确标为“更新”；更新前保护草稿，生产构建预缓存对应 JS/CSS
- 无新增生产依赖；保留原数据库、记录 ID、v1 迁移与 v2 备份兼容

v0.5 仅处理首次课程时间；重复排课能力从 v0.6 开始提供。

## 本地运行

```bash
npm install
npm run dev
```

然后访问终端显示的 Vite 地址（默认 `http://localhost:5173`）。开发模式不注册 Service Worker，避免旧缓存干扰热更新。

## 检查与构建

```bash
npm run check
npm test
npm run build
```

生产文件输出到 `dist/`。浏览器验收使用 Playwright：

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
python3 -m http.server 4173 --directory dist
```

保持服务器运行，在另一个终端执行：

```bash
python3 tests/ui_acceptance.py
python3 tests/timetable_acceptance.py
python3 tests/organization_acceptance.py
```

## 数据安全

首次打开 v0.2 及后续版本时，旧版 `jinriji:entries` 会一次性迁移到 IndexedDB。迁移事务成功后才写入完成标记，旧数据不会删除，并会额外保存在 `jinriji:migration-backup:v1`。

v0.5 不升级数据库版本，不批量改写旧记录。可选的 `dateOnly` 保存全天事项的日历日期，旧记录仍从原时间戳读取；`completedAt` 保存新完成动作的时间；课程增加可选全天标记。旧字段和 ID 均保留。

v0.6 继续使用原数据库表，为学期、规则与单次调整添加可选 revision，用于检测过期编辑。重复课程由规则按需计算，不批量生成记录；旧记录与旧单次课程仍可读取。

v0.6 的 v3 JSON 包含记录、课程（含最近删除）、学期、重复规则、单次调整、主题和旧玻璃字段。v1/v2 导入仍支持，但这两种旧格式不含排课表；导入前会明确说明将替换当前排课数据。v0.5 及更早版本不能完整读取 v3，请勿使用旧版应用覆盖新版备份。

从 v0.7 起实际导出版本为 v4，进一步包含条目的可选 pinned、tags、repeat、repeatNextId。没有数据表迁移；旧记录不填这些字段也可使用。继续读取旧 v1/v2/v3，导入和恢复仍在全表事务中完成。v0.6 及更早应用不支持 v4，请在回退旧应用前保留独立 v4 文件；不要用旧应用覆盖新版数据。

草稿、本地恢复点不在备份文件中。记录草稿独立保存在此浏览器的 `jinriji:drafts:v1`，不是跨设备同步。学期／排课表单尚未保存时会在关闭、返回或刷新前保护输入；这类设置表单不提供刷新后自动恢复。

导入先完整校验并预览，确认后在一个 IndexedDB 事务内保存恢复点、替换记录、课程、学期、规则、单次调整及主题。失败整笔回滚。设置中的恢复操作也会先将当前数据保存为新的恢复点；旧版恢复点仍可读取，仅保留最近一个恢复点，不自动清理最近删除。恢复点和草稿不能抵御浏览器数据清除，重要内容请导出为独立文件。单个备份限制 10 MB；记录和课程各最多 20,000 条，学期 100 个，排课规则 2,000 条，单次调整 10,000 条。

移除排课时段使用逻辑删除并保留历史例外。修改学期或规则时，若现有单次调整变得无效，会拒绝保存并保留输入；请先恢复相关课次再修改。回退应用版本前请保留最新版独立备份（目前 v4），旧版本不具备完整的新功能备份能力。

液态玻璃开关已从设置移除。旧备份的 `glass` 字段仍兼容读取和存储，但不再关闭界面材质；新导出写入 `glass: true`。系统降低透明度偏好仍生效。

## 部署

推送到 `main` 分支后，GitHub Actions 的质量工作流会运行类型检查、单元测试、生产构建与浏览器验收，独立的 Pages 工作流会部署 `dist/`。发布前须先通过本地检查。

`npm run build` 会生成版本化资源预缓存清单，Service Worker 只有在所需 HTML、JS、CSS 缓存成功后才安装完成。字体分片按需缓存；离线时未缓存的字形可使用系统字体回退。
