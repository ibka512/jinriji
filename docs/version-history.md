## v0.7 · 长期使用效率

- 侧栏移除「今」字印章，保留纯文字品牌，调整宽度、间距、对齐和底部状态；窄侧栏保留可读品牌。
- 侧栏与手机 Tab Bar 共用两态图标：未选中为线框、选中为带镂空细节的实心图形，继续提供 aria-current 与文字名称。
- 记录支持置顶、标签、按标签筛选和仅看置顶；搜索也可匹配标签。每条最多 12 个标签，每个最多 20 字。
- 记录页的“整理”支持当前结果全选、批量置顶／取消置顶、添加标签、完成待办及移至最近删除。删除需确认，发生版本冲突则整批回滚；切换筛选或页面会清空选择。
- 待办可按原计划每天／每周／每月重复，完成后生成一个下一次，逾期时跳过遗漏日期。月末在短月收拢，但保留原日号，之后恢复；不预先堆积未来任务。
- 快捷操作：`N` 按当前页面新建、`/` 搜索、`Alt + 1–4` 切换页面、`?` 查看帮助；保留 `⌘ / Ctrl + K` 快速记录和 `⌘ / Ctrl + Enter` 保存。输入文字时不触发单键操作。
- 离线时显示简短提示，设置区区分离线页面是否就绪；开发预览不缓存页面。网络提示不代表云同步，也不用于禁用编辑。
- 完整备份升级为 v4，包含置顶、标签、重复规则及下一次关联，继续读取 v1/v2/v3。无新增依赖、不升级数据库、不批量改写旧记录。

首次使用：记录卡右上角可置顶；编辑器“标签”可分类；记录页“整理”可批量操作。编辑待办时设置日期并选择“重复”，关闭重复请编辑尚未完成的下一次待办。

重复规则保留设置时的时区。撤销完成会同时撤销未编辑的自动生成项；如果下一次已经编辑、删除或完成，会拒绝撤销，保护后续内容。导入恢复会递增版本，因此不会把恢复后的下一次视作“未编辑”。完成历史仍可查看下一次；删除过去的一次不会删除下一次。

网络提示参考 [MDN navigator.onLine](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/onLine) 的限制，只提供提示；离线页面就绪依据 [Service Worker 控制状态](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/controller)，不保证未缓存字体可用。数据仍应定期导出。

## v0.6 · 课程与学习安排

- 学期：设置第一周周一、1–60 周及当前学期；按学期切换查看，保留历史课程
- 排课：每门课程可设置多个时段，支持每周／单双周、起止周、上课时间和地点
- 单次调整：点击具体课次调课或停课，可恢复原安排，不修改其他课次
- 课程表：手机按日阅读，宽屏按时间轴查看一周；重叠课程并排，时间范围随本周课程收拢
- 课程关联记录：从课程详情记笔记，也可在记录编辑器关联便签／待办／日程；删除课程不删除笔记
- 计划分段切换采用 [UI-001 · Segmented Switch](https://github.com/ibka512/ibka-ui-designs/tree/main/components/segmented-switch)：等宽胶囊、一个共享滑块、按压反馈和颜色过渡；适配深色、键盘与减少动态
- 新完整备份格式 v3 包含学期、排课规则与单次调整；仍可导入 v1/v2，并支持全表事务回退
- 沿用数据库版本与已有表，无新增生产依赖，不自动转换旧单次课程

使用顺序：计划 → 课程表 → 新建学期 → 添加课程 → 打开课程详情 → 添加时段。之后点击课程表中的具体课次进行调整。

学期时区固定为创建时的设备时区；跨时区查看时，课程表按学期当地时间显示，首页及本周安排按设备时间显示。单双周以学期第一周为准。当前不提供跨夜课、跨学期调课、教务导入、系统提醒或云同步。
