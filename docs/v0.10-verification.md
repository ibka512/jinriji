# v0.10 日常体验打磨 · 本地验收

日期：2026-09-01。代码基线：`2513ae6`（v0.9.0）；本轮改动尚未提交、推送或部署。此前发布记录不作为本轮远程验证证据。

## 已完成范围

- 内容安全：整篇“转为待办”改为创建独立关联待办，源笔记不改动；旧版已转换的富文本待办保留结构化编辑，数据层拒绝静默降为纯文本。图片、表格和笔记链接的语义保真已验证。
- 日期闭环：新日程必须有日期，从当前周或具体日期继承默认值；旧版无日期日程有“待安排日期”入口，无日期待办仍可使用。
- 写作：撤销、重做、标题和加粗直接可达；其余工具按用途归组。阅读与编辑共享标题和正文位置，长文固定返回、完成与保存状态；表格上下文工具不再挤动正文。
- 整理：筛选与排序折叠、统一清除条件、搜索命中片段、批量移入笔记本；修复“全选”越过当前笔记本范围的问题。首批展示 80 条，可继续加载。
- 排课：新建课程可同时保存第一个上课时段，失败整体回滚；保留单次课程与仅建资料入口。课程详情留在计划内，旧课程链接仍兼容。
- 反馈：版本号统一来源、设置常驻更新入口与离线重试、启动失败就地重试与数据保护说明。TXT/Markdown 导出边界在操作处说明，并提供完整备份入口。
- 视觉和动效：保留和纸、中文衬线及胶囊导航；设置改用齿轮并移除无关侧栏内容，空卡收紧。通知退出后隐藏交互语义；原生对话框渐进增强退出效果，键盘高频操作不增加等待，减少动态模式不做位移。

数据库仍为 v3，完整备份仍为 v6；旧数据读取、草稿、历史、导入恢复点均保留。不新增生产依赖，代码回退无需数据迁移。

## 本地规模基线

以下为本机 Chromium 单次验收的端到端测量，不是低端手机承诺，也不是冷启动基准。记录测试用合成笔记，图片测试用带像素噪声的 PNG。

| 数据量 | 测量动作 | 本次结果 |
| --- | --- | --- |
| 500 条记录 | 导入并进入列表 / 输入搜索 | 569ms / 7ms |
| 2000 条记录 | 导入并进入列表 / 输入搜索 | 1749ms / 13ms |
| 1 张图片，资产约 0.30MB | 已加载应用刷新至可用 | 53ms |
| 20 张图片，资产约 6.03MB | 已加载应用刷新至可用 | 127ms |

列表首批 80 条、继续加载到 160 条、搜索上下文和空结果恢复均有断言。已缓存搜索文本，字符统计不再随纯选区变化扫描全文；尚未改为图片按需读取，刷新仍读取全部资产。这组数据未证明大量高清图片或长期大库的性能，应继续量化后再优化。

## 尚未验证与发布边界

- 未实测真实 iPhone/Safari、Android 中文输入法、软键盘遮挡、系统选择菜单、VoiceOver 或低端设备帧率。
- 对话框离散退出使用渐进增强；不支持的浏览器仍依赖原生 dialog 开关，本轮未做真实 Safari 动效验收。
- 本机没有进行真实线上旧版本到新版本的 Service Worker 升级演练；保存保护与更新分支由单元、隔离浏览器测试覆盖，发布时仍需验证。
- 不把桌面视口模拟和合成输入测试表述为真机通过；v1.0 候选版仍需以上设备与恢复流程验收。
- 本轮未运行远程 CI，未提交、推送或部署。GitHub Actions 已补入成熟度验收脚本，待用户指令发布时执行。
