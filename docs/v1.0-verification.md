# v1.0.0-rc.1 · 本地候选版验证

日期：2026-09-01。基线为未提交的 v0.10 工作树；本轮继续开发，没有重置或覆盖用户改动。当前未提交、未推送、未部署，不能表述为正式发布。

## 设计与操作结果

- 保留和纸、本地中文衬线、四套莫奈主题、纯文字侧栏、胶囊导航、圆形加号和共享两态图标。没有新增背景色相、装饰卡片或说明文案。
- 动效只有反馈、状态指示、空间连续或避免突变四类目的。键盘导航、输入、撤销和格式快捷操作无等待；指针按压最多 160ms，菜单 180ms，原生短表单 240ms，导航延续 UI-001。没有 `transition: all`、`scale(0)`、长于 300ms 的新 UI 动效或触摸端残留 hover。
- `details` 使用原生语义；新浏览器渐进增强内容退出，旧浏览器即时开关。关闭时面板立即 `inert`，Escape 返回 summary；快速重复开关不阻断操作。
- 待办持久化与视觉反馈并行，反馈不延迟数据库写入或错误；键盘完成后跳到下一条可见待办，不会聚焦已折叠的完成组。
- 通知悬停或聚焦时暂停；有明确关闭按钮，Escape 可关闭，退出后 `hidden + inert` 并返回原位置或当前标题。连续通知不会被上一条定时器隐藏。
- 通知的实时播报只包围消息文本，撤销和关闭保持独立按钮语义；320px 手机与 1440px 桌面的可见控件均有可访问名称，按钮、链接和 summary 达到 44px 触控基线。
- 长文顶栏和工具栏用实际测量高度衔接，320px／200% 字号仍可返回和完成。四主题深浅色正文、辅助文字与主操作最低对比度实测均不低于 5.43:1。
- Service Worker 缓存由版本和构建指纹隔离。实际演练覆盖下载失败、持续重试、成功激活、删除旧缓存、记录保留、断网刷新与离线新增笔记。

## 已执行验证

最终本地验证全部通过：TypeScript 类型检查；14 个测试文件、112 项单元测试；生产构建；`git diff --check`；Chromium 49 组流程（既有 40 组全回归、候选版 8 组、实际更新恢复 1 组）；WebKit 8 组候选版核心流程。两套引擎合计执行 57 组浏览器流程，生成 63 张 Chromium 截图和 7 张 WebKit 截图。WebKit 离线自动刷新不计入通过项，边界见下节。

最终生产构建主 JavaScript 为 658.85kB（gzip 207.96kB），CSS 为 83.16kB（gzip 16.56kB）；保留 Vite 的主包超过 500kB 提示，后续应按真实启动数据决定是否拆包。本地最终单次规模基线：500 条记录导入并进入列表 573ms、搜索 8ms；2000 条为 1795ms／16ms。1 张约 0.30MB 图片刷新 46ms，20 张约 6.03MB 为 44ms。数据受本机缓存与调度影响，只用于发现数量级退化，不是低端设备承诺。

## 引擎与设备边界

- Playwright WebKit 通过键盘/完成、菜单/弹层、四主题深浅色、320/768 大字号、备份恢复、图片表格及课程事务流程。该引擎来自 WebKit 主干，不能冒充品牌 Safari。[Playwright 官方说明](https://playwright.dev/python/docs/browsers)
- WebKit 1.55 的 `BrowserContext.set_offline()` 后自动化 `page.reload()` 在本机报告内部错误。用只返回固定 HTML 的最小 Service Worker 仍可复现，排除了今日记数据与缓存实现；因此 WebKit 自动化不宣称离线刷新通过。WebKit 本身支持 Service Worker 离线应用，[WebKit 官方说明](https://webkit.org/blog/8090/workers-at-your-service/)。真实 Safari 离线刷新仍是发布阻塞项。
- 未实测真实 iPhone/iPad Safari、Android 中文输入法与虚拟键盘、VoiceOver、系统文字选择菜单或低端设备帧率。桌面视口模拟、组合事件和 Playwright WebKit 均不能替代这些测试。
