# v0.10 写作、整理与数据安全

## 如何写作

笔记在页面中阅读和编辑，不使用遮罩、悬浮窗口或全屏弹窗。宽屏将笔记本筛选、搜索与紧凑列表放在正文旁；平板与手机按可用宽度收起列表。点击正文或“编辑”才进入书写；手机写作时隐藏 Tab Bar。“更多”收纳查找、排版、笔记链接、选段待办、图片、表格、历史和导出；“笔记信息”收纳笔记本、标签及课程。

“专注”只收起页面导航和列表，不重新创建编辑器，光标和撤销栈保留。笔记的阅读链接为 `#notes/item/:id`，编辑链接为 `#notes/item/:id/edit`，新建会话为 `#notes/new/:id`。刷新编辑链接会读取本机记录或恢复草稿。

新建便签后可直接输入，工具栏提供常用格式；`# `、`## `、`- `、`1. ` 等输入规则由 Tiptap 处理。已有纯文本与纯文本粘贴按字面保留，不会批量解释 Markdown。正文上限沿用 200,000 UTF-16 字符；显示统计按非空白 Unicode 码点计数，两者在 emoji 等场景不同。

查找为区分大小写的字面匹配，可跨同一段中的不同格式，不跨段落；首次“替换此处”先选中匹配，确认后再替换，“全部替换”可一次撤销。不使用正则表达式。链接只接受 http、https、mailto；渲染时不使用任意 HTML。

## 保存与恢复

便签停止输入约 600ms 后：先持久化恢复草稿，再在事务中检查原记录版本、写入正文与必要历史；成功后才报告保存完成。写入期间继续输入会安排下一次保存，列表同步显示已提交内容。两个窗口使用独立恢复草稿，记录 revision 不一致时拒绝覆盖；可另存副本。页面导航串行等待保存，失败时留在编辑页，浏览器返回也使用同一道保护。输入法组合输入和图片处理期间不切换页面。

## 整理、图片与表格

- 单层笔记本支持创建、重命名、删除与批量移动。整理时全选只覆盖当前筛选范围；移动只接受笔记，遇到版本冲突或目标笔记本失效会整体回滚。删除笔记本与笔记移至未分类在同一事务中完成，递增笔记版本，避免旧编辑器覆盖分类变化。
- 模板永远新建一篇；空白／每日记录／课堂笔记／读书摘录不修改已有正文。笔记链接保存稳定 ID，标题变更不会断链；关联记录由现有笔记和来源待办计算，不维护第二份易失配的关系表。
- 选段转待办先保存来源笔记，再新建待办，原文不删除；来源课程一并继承。待办可以回到来源笔记继续阅读。
- 图片仅在本地解码，接受 PNG/JPEG/WebP，输入最大 10MB、1600 万像素，输出最长边 1600px、约 512KB；canvas 编码去除原文件元数据，不保留原始大图。图片插在当前顶层段落或表格之后，避免拆分表格。
- 图片以独立 `assets` 表保存，正文／历史引用 ID，避免每次版本复制图片。导入保留旧资产供草稿和历史使用；同 ID 对应不同图片时整次导入回滚。当前不自动回收未引用的图片，以免删除恢复副本需要的内容。
- 基础表格 3×3 起步，支持增删行列，最多 20 行、8 列，不支持嵌套、合并、公式或列宽拖动。结构不受支持的粘贴不加入正文。删除表格可用编辑器撤销恢复。

刷新或意外关闭前仍有未提交输入时会请求浏览器离开确认，但浏览器／系统不保证总能显示确认，崩溃前最后一次尚未落盘的输入仍可能丢失。刷新后可从草稿提示继续。浏览器关闭、清除站点数据和设备损坏仍需要独立备份应对。

撤销／重做属于当前编辑会话；历史属于有上限的本地检查点，不是每个字符的无限版本控制。每篇最多 20 个历史，全站最多 100 个；达到上限移除最旧历史，当前记录不受影响。历史和正文写入同一事务，历史写入失败也不假报正文成功。恢复前保存当前内容并强制保留旧版本。

## 兼容性与回退

- `Item.document` 为可选 Tiptap JSON；存在时为正文真源，`body` 是从结构投影的检索文本。解析备份时校验两者一致。
- 旧记录读取不批量改写；进入编辑器时按原有换行映射为段落，首次保存才带结构化正文。笔记创建关联待办时不改变源文档。旧版已经转换的富文本待办继续用结构化编辑器，仓储拒绝仅凭纯文本投影覆盖结构化内容。
- Dexie 数据库 v2 新增 `drafts` 和 `noteVersions`，v3 新增 `notebooks` 和 `assets`，不重写旧正文。旧草稿在事务内复制并写入标记；原 localStorage 不删除、不重写，迁移失败不会写完成标记，可重试。迁移成功后不再从旧副本复活已完成的草稿。
- 完整 JSON 导出升级 v6，继续读取 v1–v5，包含笔记本及当前记录（含最近删除）引用的图片。导入整份替换并建立可逆恢复点，条目、课程及笔记本 revision 递增防止旧窗口覆盖。旧版备份不含的笔记本和排课会被替换为空；草稿、历史、光标和本地偏好不是导出文件的组成部分。
- 旧应用不支持新版数据库、图片或笔记本。回退前先导出独立 v6 备份，并将重要正文导出 TXT／Markdown；在支持 v6 的版本恢复完整结构。不要清空浏览器数据以强行降级。总备份上限 64MB，导出和导入都会检查。

## 已知范围

Markdown 不保留高亮／下划线；表格导出为基础 Markdown 表格，图片用说明占位，笔记链接保留应用内 ID；TXT 不保留格式或图片。完整图片必须通过 JSON 备份带走。当前不含任意文件附件、手写、OCR、嵌套笔记本、自定义模板、实时协作和云同步。

自动化覆盖 Chromium；模拟组合输入不是实际输入法或虚拟键盘。真实 iPhone Safari、Android 中文输入法、输入法候选词与系统选择菜单仍需真机检查。编辑器使生产 JS 体积增加，当前构建会提示大于 500kB 的单块；压缩传输约 207kB，离线缓存覆盖该文件。
